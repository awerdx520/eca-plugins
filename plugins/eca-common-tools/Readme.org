* 概述

  这是一个 ECA (Emacs Code Assistant) 插件，通过一个 MCP 服务器提供多个工具：

  - =render_plantuml= — 将 PlantUML 源码渲染为 SVG 无损矢量图片（base64 内联），支持 =background= 背景色参数（暗色主题可读）
  - =pandoc_convert= — 文档格式转换（Markdown ↔ Org ↔ HTML ↔ LaTeX ↔ DOCX 等）
  - =pandoc_list_formats= — 列出 pandoc 支持的全部输入/输出格式
  - =plantuml_validate= — 仅校验 PlantUML 源码语法，不返回图片；复用渲染通道（HTTP 200/400）判断，失败回退 CLI
  - =json_format= — JSON 格式化/压缩/排序，解析错误返回位置信息（纯 JS 零依赖）
  - =csv_to_markdown= — CSV → Markdown 表格，支持引号包裹字段与自定义分隔符（纯 JS 零依赖）
  - =regex_test= — 正则测试：pattern + flags + text → 匹配位置/捕获组；子进程隔离 + 2s 超时防灾难性回溯（纯 JS 零依赖）
  - =test_result_summarize= — 解析 pytest/jest/go test 输出，自动识别框架，只返回失败用例与错误摘要（默认 top 10，含文件:行:列）
  - =stack_trace_analyze= — 多语言堆栈解析（Python/JS/Java/Go），输出错误类型+调用链+首个项目文件位置
  - =code_block_extract= — 从文本提取代码块，支持语言过滤与未闭合检测（LLM 输出截断预警）

  采用 *统一 MCP 服务器 + 模块化工具* 架构：一个 MCP 进程包含全部工具，
  未来新增工具只需添加模块文件并在 src/index.mjs 注册，无需新增 MCP 服务器。

  采用 *二层架构*：

  1. =L1 preRequest Hook= — 每次 LLM 请求前自动注入画图规则（PlantUML 语法、禁止行为、自检清单）
  2. =MCP 服务器= — 提供十个工具，模型输出 =@startuml= 块或需要文档转换时主动调用

* 工作原理

  =render_plantuml= 渲染链路：

  PlantUML 源码 → pre-request hook 注入画图规则 → LLM 输出 @startuml 块
  → LLM 调用 render_plantuml 工具 → MCP 服务器执行渲染（优先常驻 HTTP
  服务器 plantuml --http-server:18080，源码经 encodeurl 编码后 GET /svg/<encoded>，
  耗时约 16ms；HTTP 不可用时回退 plantuml -pipe -tsvg）
  → base64 SVG data URI 返回给 LLM → 嵌入回复展示。

  背景处理：PlantUML 通过 SVG 根元素 CSS background 设置背景，但 librsvg（Emacs image-mode
  渲染器）不支持该属性，暗色主题下实际渲染为透明背景、黑字不可读。render_plantuml 支持
  background 参数（十六进制色值，如 '#ffffff'），渲染后注入标准 <rect> 背景元素（librsvg
  兼容），调用时传 background:"#ffffff" 保证暗色主题可读；传 "none" 或不传保持透明。

  =pandoc_convert= 转换链路：

  源文本 → LLM 调用 pandoc_convert 工具 → MCP 服务器通过临时文件调用 pandoc CLI
  → 返回转换后文本 → LLM 嵌入回复。

  新增 util 工具（json_format/csv_to_markdown/regex_test）为纯 JS 实现，不依赖外部
  CLI；regex_test 通过子进程执行正则并超时 kill 防 ReDoS。新增的
  test_result_summarize/stack_trace_analyze/code_block_extract 均为纯 JS 启发式解析，零依赖。

* 配置

  常驻 HTTP 服务器端口固定为 18080；被占用时自动回退 CLI 模式。

* 依赖

  - ~plantuml~ CLI（需要 Java 运行环境）— 用于 render_plantuml
  - ~pandoc~ CLI — 用于文档格式转换
  - Node.js 运行时

* 开发

  测试 MCP 服务器：

  #+BEGIN_SRC bash
  npm install && node src/index.mjs
  #+END_SRC
